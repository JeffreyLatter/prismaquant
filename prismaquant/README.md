# PrismaQuant Package Notes

This package README intentionally stays short. The canonical user-facing
overview lives in the repository root at `README.md`.

Current live entrypoints:

- `python -m prismaquant.incremental_probe`
- `python -m prismaquant.incremental_measure_quant_cost`
- `python -m prismaquant.iterate_perturbed_allocation`
- `python -m prismaquant.polish_from_assignment`
- `python -m prismaquant.export_native_compressed`
- `python -m prismaquant.validation_harness`

Legacy additive, interaction, Block-CLADO, dense-cone, and adjoint tools remain in
the package for artifact replay and comparison. Historical docs and launchers are
under `archive/legacy_frontiers_2026-05-06/`.
