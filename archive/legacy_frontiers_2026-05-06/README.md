# Legacy Frontier Archive

Archived on 2026-05-06 during the PrismaSCOUT cleanup branch.

This directory preserves old frontier-search material that is still useful for
historical comparison and artifact replay, but no longer describes the current
recommended path.

Contents:

- `docs/`: Block-CLADO, dense-cone, adjoint, handover, and result notes.
- `launchers/`: experimental and smoke launchers for those older paths.

The live documentation is in `docs/`, and the live launcher examples are in
`examples/launchers/`.
